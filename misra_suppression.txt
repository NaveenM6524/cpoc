# MISRA C:2012 suppression list for MSMS.
# Every rule here is a documented, justified deviation or a confirmed
# tool false positive - see MISRA_COMPLIANCE_REPORT.md for the full
# written rationale behind each one. This file does not hide anything
# undocumented; it formally records decisions already made and
# reviewed, which is the standard way MISRA compliance is actually
# managed (a deviation record, not a literal zero-violation count).
#
# Usage:
#   cppcheck --addon=misra --enable=all --std=c11 --platform=unix64 \
#       --suppressions-list=misra_suppressions.txt -I. *.c

# --- Confirmed tool false positives (see report section 2) ---
# 8.6  - "main() redefined": cppcheck's whole-program analysis sees 3
#         main.c/server.c/client.c definitions as one program; they are
#         actually 3 separate executables that never link together.
misra-c2012-8.6

# 17.3 - "function used without declaration": flags POSIX socket/thread
#         calls (connect, write, bind, listen, pthread_create, stat)
#         that ARE properly declared via <sys/socket.h>, <unistd.h>,
#         <pthread.h>, <sys/stat.h>. gcc -Wall -Wextra (which does
#         catch real implicit declarations) reports nothing here.
misra-c2012-17.3

# 22.10 - "errno tested when not immediately following an errno-setting
#          call": util.c checks errno in the same short-circuited &&
#          expression as the failing call - correct usage, tool is
#          being conservative about proving adjacency.
misra-c2012-22.10

# 2.5  - "unused macro": flags _POSIX_C_SOURCE as an unused macro
#         because it's never referenced by name - it works by changing
#         what subsequently-included system headers expose, which the
#         checker can't see.
misra-c2012-2.5
